# Material Heroes

Pequeno repositorio de practica para organizar informacion sobre heroes, misiones, ciudades e historia.

## Contenido

- `heroes.md`: lista breve de heroes y sus habilidades.
- `misiones.md`: objetivos y encargos principales.
- `ciudades.md`: lugares importantes del mundo del proyecto.
- `historia/linea-tiempo.md`: eventos ordenados en forma de lista.
